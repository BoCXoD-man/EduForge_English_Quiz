# EduForge English Quiz

**Учебный проект на Python — интерактивная викторина для изучения английских слов.**

## О проекте

**EduForge English Quiz** — один из практических проектов авторского учебного курса по программированию, который я разрабатываю для обучения своих студентов.

Моя задача как преподавателя — не только объяснять синтаксис и основные концепции Python, но и помогать студентам применять полученные знания на практике. Поэтому курс включает небольшие законченные проекты, в которых отдельные темы объединяются в работающие приложения.

English Quiz — пример такого подхода. В процессе разработки викторины учащиеся знакомятся с созданием графических интерфейсов, работой со словарями и случайными значениями, обработкой действий пользователя и организацией игровой логики.

Проект задуман как наглядный переход от изучения отдельных конструкций языка к созданию собственного приложения.

## Возможности

- Графический интерфейс на базе Tkinter.
- Проверка знания английских слов и их переводов.
- Три варианта ответа на каждый вопрос.
- Случайный выбор слов и перемешивание вариантов ответа.
- Подсчёт правильных ответов.
- Обратная связь после выбора ответа.
- Итоговый результат по завершении викторины.
- Возможность начать игру заново.

## Технологии

- **Python** — основная логика приложения.
- **Tkinter** — создание графического интерфейса.
- **random** — случайный выбор слов и вариантов ответа.
- **Словари Python** — хранение английских слов и переводов.

Проект использует стандартные возможности Python и не требует установки сторонних библиотек.

## Запуск

Проверьте, что Python установлен на вашем компьютере, затем выполните команду в терминале из папки проекта:

```bash
python english_quiz.py
```

В Windows также можно использовать команду `py english_quiz.py`.

## Учебная ценность

Проект демонстрирует, как базовые инструменты Python можно объединить в законченное интерактивное приложение. Он служит частью практических материалов моего курса и может использоваться для разбора структуры программы, изучения взаимодействия с пользователем и дальнейших самостоятельных доработок.

Возможные направления развития — расширение словаря, настройка количества вопросов, ограничение времени на ответ и добавление режима ввода перевода без вариантов ответа.

## Авторский подход

EduForge — название серии учебных проектов и материалов, созданных для практического обучения программированию. Каждый проект этой серии посвящён отдельной задаче и помогает закреплять изученные темы на конкретном примере.

**English Quiz — один из проектов этой серии, объединяющий учебную цель и практическую разработку на Python.**
